# Portuguese Bank Marketing Prediction

## Project Overview
This machine learning project predicts whether a bank client will subscribe to a term deposit based on direct marketing campaign data from a Portuguese banking institution.

## Workflow & Methodology
* **Data Cleaning & Preprocessing:** Handled missing values, encoded categorical variables, and scaled numerical features.
* **Feature Selection:** Identified the top 15 most influential features using Random Forest feature importance.
* **Handling Imbalanced Data:** Applied SMOTE (Synthetic Minority Over-sampling Technique) to balance the target classes.
* **Model Building & Evaluation:** Trained and compared Logistic Regression, Decision Tree, Random Forest, and Gradient Boosting classifiers using Accuracy, Precision, Recall, F1-Score, and ROC-AUC.

## Technologies Used
* Python 3
* Pandas, NumPy
* Scikit-Learn, Imbalanced-Learn (SMOTE)
* Matplotlib, Seaborn
